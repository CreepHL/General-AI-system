# General AI System

借鉴 Atoms 多智能体产品的协作方式，使用 Vue 3 + FastAPI 实现的的通用 AI 应用平台原型。

## 技术栈
- Frontend: Vue 3, Vite, Vue Router, Pinia, Element Plus, ECharts
- Backend: FastAPI, SQLAlchemy 2, Pydantic
- Database: 默认 SQLite 开箱即用；可通过 `DATABASE_URL` 切换 MySQL

## 启动（Windows PowerShell）
后端：
```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
API 文档：http://127.0.0.1:8000/docs

前端（Node.js 18+）：
```powershell
cd frontend
npm install
npm run dev
```
浏览器打开 http://localhost:5173。

首次启动自动创建 `backend/general_ai.db` 并写入演示数据。MySQL 示例：
`DATABASE_URL=mysql+pymysql://user:password@127.0.0.1:3306/general_ai_system?charset=utf8mb4`

## 页面功能
- 首页：统计卡片、快捷入口、运行任务、Agent 状态、活动流；对话框支持选择 Agent 或团队。
- 对话与任务：用户选择agents并编排流程以实现任务
- 团队管理：卡片展示、编辑团队、使用团队跳转任务大厅。
- 任务大厅：新建任务、选择团队/Agent、串行/并行/自由讨论/可视化流程编排、查看进度。
- 平台配置：大模型、Agent、Prompt、Skill、Tools、知识库、成本看板。
- 首次启动或升级后会补充 App/网页开发角色的默认 Prompt、Skill 与 Tools 目录；已有同名标识配置不会被覆盖。Agent 可分别绑定一个 Prompt、多个 Skill 和多个 Tools。
- 模型配置卡片可直接启用或停用模型；停用后绑定该模型的智能体无法继续调用，模型密钥和其他配置会保留。
- 大模型请求超时可设置为 5–3600 秒，实际调用和连接测试均使用该设置；供应商或中间网关的独立超时限制仍可能提前结束请求。
- 顶栏：General AI System 固定标题、语言切换、暗色/亮色、全屏、头像与姓名。

## 重要边界
在“对话与任务”创建任务时开启“生成可操作应用”，描述 2048、计算器或费用工具等单页应用需求。模型返回完整的 HTML、CSS、JavaScript 后，平台会检查响应是否正常结束、文件结构和 JavaScript 语法；校验通过才保存新版本，并在会话右侧的隔离 iframe 中直接运行。继续在同一任务中发送修改要求，会把上一可用版本交给模型生成下一版；版本菜单可查看和恢复旧版。生成失败会显示“生成失败”，旧版仍可预览，使用“重试上一条消息”继续尝试。

旧任务即使创建时没有开启应用模式，只要保存了用户需求或任务描述且尚无应用版本，也能在会话顶部点击“按原需求重新生成预览”。平台会汇集该任务的历史用户需求重新构建应用，保留原聊天消息；没有历史消息时使用任务描述。生成失败后可再次点击重试。重新生成会调用已绑定的模型，历史聊天中展示的 HTML 代码本身不会自动作为可操作版本导入。

任务标题栏提供预览开关；关闭后整个右侧预览区隐藏，对话区展开。此选择按任务保存在当前浏览器，关闭预览不会删除应用版本或页面数据。

当前预览范围是无需外部依赖的单页浏览器应用，不支持直接运行模型生成的多文件后端项目或原生手机 App。隔离预览允许应用接收表单提交事件，但禁止表单向外提交。平台后端为每个应用任务提供数据库 JSON 键值存储：`window.appStore.get(key)` 读取启动快照，`await window.appStore.set(key, value)` 保存并在失败时抛错。数据按任务区分，应用版本共享数据；同一平台服务的其他浏览器可以读取。每个任务最多 100 个键，每项最多 60 KB，保存需要后端可用。首次打开时会把当前浏览器的旧应用数据中服务端尚无的键迁移过去，服务端已有键优先，旧本地数据保留。它不提供独立的业务 API、账号、权限或第三方服务，应用数据与当前平台其余接口一样尚无用户隔离。旧版本仍按原代码运行，可点击“修复最新版”结合历史需求生成新版本；模型生成的交互仍取决于模型输出。后端需要 Node.js 以执行 JavaScript 语法检查。

会话任务已支持通过平台配置中的 OpenAI 兼容模型端点生成真实回复。先在“大模型配置”填写 Base URL、模型名称与 API Key，保存后点击“连接测试”；再在“智能体配置”中绑定模型，并选择对应的 Prompt、Skill 和 Tools。之后在“对话与任务”创建任务并发送消息，单个或多个智能体会按串行/并行模式回复。模型调用失败时，用户消息仍会保存，可点击“重试上一条”。

默认开发角色覆盖产品经理、交互设计师、架构师、网页前端、后端、移动 App 和测试工程师。绑定的 Prompt 与 Skill 会进入该 Agent 的系统提示；独立的 Agent 补充指令会保留。应用任务会实际调用所选 Agent：通常先依次收集其他角色的建议，再由前端 Agent 生成应用；流程图编排遵守节点顺序，位于前端之后的角色只提供对生成代码的建议。其他协作模式的应用构建也按上述顺序执行，暂不并行。对话展示各 Agent 的真实回复，以及当时使用的模型、Prompt、Skill 和配置的 Tools；模型的应用说明与网页代码分开保存。Tools 目录目前用于配置角色绑定和用途说明，自动工具调用执行器尚未接入，不能据此认为文件、浏览器或命令已经实际运行。

编辑 Agent 时可按名称或说明搜索并勾选 Skill 和 Tools，展开查看配置正文；Prompt 也可查看正文。配置卡片展示绑定结果，停用项不会进入执行上下文；“按角色补充推荐”仅填充尚未绑定的类别，保存前可继续调整。所有已绑定且启用的 Skill 均会带入模型，Prompt 与 Skill 内容合计超过 50000 字符时会提示精简。

会话及任务启动支持 SSE 流式显示模型回复；连接测试仍为普通请求，后台队列尚未接入。“自由讨论”按串行执行。文本类附件（txt、md、csv、json）的内容可加入模型上下文，其他附件目前仅存储与下载；工具连接器仅保存选择，尚未执行。API Key 不返回前端明文，但仍存于数据库；生产环境应加密存储，并加上认证、RBAC、审计及调用限额。

成本看板从模型调用日志汇总成功调用次数和供应商返回的 Token 用量，历史上未记录的调用不会追溯补算。在大模型配置中填写每百万输入/输出 Token 单价及币种后，新调用会按供应商实际 usage 估算成本；未返回 usage 或未配置单价的调用保留记录，但不虚构 Token 或金额。连接测试也计入调用记录。

知识库支持创建与编辑、上传 TXT/MD/CSV/JSON/文本型 PDF（每份最大 12 MB）、自动切分、关键词检索和删除文档。新建对话任务时可选择最多 5 个已启用知识库，模型调用前会把与本轮问题相关的片段加入上下文。扫描版 PDF 目前需要先完成 OCR；当前检索为关键词匹配，不包含参考项目的向量检索、发布版本和权限隔离。

新建对话与任务的协作模式包含“流程图编排”：选择多个智能体或团队后，可拖动节点调整执行顺序。流程保存到任务 workflow.nodes，串行执行器与流式执行器都按该顺序逐个调用模型，前一个智能体的回复会传给下一个智能体。当前流程为线性顺序，不支持条件分支或并行分叉。
